# Caption and keyword

## Caption
- **Line 1** is the promise or the hook, because only the first line shows before "more".
- Then 2 to 4 short lines: what the viewer gets and why it works. No filler, no "link in bio".
- End with the one ask.
- 3 to 5 relevant hashtags. More does not help.

## Keyword (optional)
Use a comment keyword only when **all three** are true before you post:
1. The message that follows is automated and tested.
2. It delivers a real thing (a link, a file, a prompt), named in the caption.
3. You can say exactly what it contains.

If not, use a different ask ("save this", "send it to someone who edits video"). Never promise a DM you cannot
send.

- One short keyword in capitals, easy to type on a phone, different for each type of post so you can tell which
  one worked.
- Say it in the caption's first line or last line, in the video, and on the last screen.

## First comment
One useful line that adds a fact or a pointer that needs no link. Do not repeat the caption.

## Note
In a small study of niche reels (17 with a keyword ask vs the rest), reels with the ask got about 18.9 shares per
1,000 plays against 32.2 without. A keyword ask can pull comments and cost shares. Choose the goal for each post:
comments and messages, or reach.

## Output
Caption, hashtags, first comment, keyword and exactly what the automated message says.
