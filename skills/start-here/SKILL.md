# Start here

One request in, one reel pack out. This runs the other skills in order. Do not skip a step, and stop and ask when a
step cannot be done honestly.

## Step 0: ask (one message, then wait)
1. The topic: a tool, repo, link or idea.
2. Who watches: one line on the audience, and one line on how the creator talks.
3. What the creator has really done or can show on screen (a real run, real screenshots). Nothing else counts as
   "I did".
4. Length: default 30 seconds.

## Step 1: findings (research-first-script)
Research the topic from primary sources. Write the FINDINGS table: claim, source, how checked, date. A claim with
no source is dropped. If fewer than three solid claims survive, stop and say the topic is too thin.

## Step 2: share block (share-check)
Fill {driver, recipient, sendLine, portableFact}. If you can run the checker, run it. If not, check it by hand
against the rules and say so. Rewrite until it passes. If no honest share block exists, tell the user the idea is
not sendable and offer one change.

## Step 3: hook (hook-writer)
Write ten, pick the best, keep two spares. 14 words or fewer, payoff first. Give the exact frame-0 picture.

## Step 4: script
One run-on breath, within the length. Every number comes from a findings row. First person only for what the
creator really did. A visual cue next to every line, and a new picture about every 3 seconds.

## Step 5: audit the script (reel-audit, the points a script can show)
Frame 0 moving and carrying the claim, claim by ~1.5 s, one idea, a picture per line, every number sourced, one
real ask. Fix what fails.

## Step 6: caption and keyword (caption-and-keyword)
Caption, 3 to 5 hashtags, first comment. A keyword only if the automated message behind it exists and holds the
thing you name. Otherwise a "save" or "send it to" ask.

## Output: the reel pack
Return one document, and save it as `reel-pack-<slug>.md` if files are available:
1. Findings table
2. Share block (passed / how it was checked)
3. Hook (+2 spares) and the frame-0 picture
4. Script, one row per line: spoken words | on screen | seconds
5. Caption, hashtags, first comment, keyword (or none)
6. **Film this:** the ordered list of what the creator must record or capture
7. **Not verified:** anything you could not confirm, and what you left out

## Rules
- Nothing is posted by this skill.
- No invented numbers, results, experience or assets. If you cannot back a line, cut it.
- Say how each step was checked (ran the script, or checked by hand), not "all good".
